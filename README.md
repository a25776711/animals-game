# wū guī 對對碰

一款 3×3 的烏龜配對小遊戲。開包、湊顏色、換獎勵，手機和電腦的瀏覽器都能玩，不用安裝。

**開始玩：<https://a25776711.github.io/animals-game/>**

## 怎麼玩

選一個幸運色，再選這局要開幾包（10、20 或 50 包）。按「開包」，九個格子會一格一格開出烏龜，開滿之後把能湊的通通湊掉：

| 組合 | 怎麼湊 | 送你 |
|---|---|---|
| 碰 | 任意 2 隻同色 | +1 包 |
| 連線 | 橫、直、斜 3 隻同色 | +3 包 |
| 全家福 | 9 隻顏色全部不同 | +5 包 |

開到幸運色的烏龜也會 +1 包。包數用完，或是你按「結算」，這局就結束了。

小提醒：平均每開一包只會拿回約 0.6 包，所以重點是「這局能撐幾回合、賺到幾包」。

## 錢和烏龜

- **錢**拿來買包，一包一錢，只能玩「烏龜對對碰」。
- **烏龜**是開包時拿到的，每開一隻就多一隻，可以拿去玩小遊戲、養龜、逛商店。
- 新來的玩家送 50 錢；第一次用 Google 登入再送 250 錢。
- 每天 06:00、12:00、18:00（台灣時間）可以到補給站領錢，當天沒領就過期。可以直接拿 200 錢，也可以賭一把轉盤（30～350 錢）。

這些都是遊戲裡的虛擬數字，不能換成真的錢，也沒有任何付費項目。

## 烏龜廣場

用烏龜玩的地方。小遊戲每一種都會扣烏龜，沒有穩賺的玩法：

- **烏龜賽跑**：押一隻，賠率最高 16 倍
- **21 點**：跟莊家比點數
- **翻牌記憶**：報名 50 隻烏龜，步數越少拿越多
- **抽卡圖鑑**：抽烏龜卡，集滿 36 種
- **養龜**：餵牠、取名字、換顏色、戴帽子
- **裝飾商店**：買背景、棋盤花紋和小龜的配件
- **聊天室**：跟所有玩家聊天

## 存檔和登入

你的進度會一直存在這個瀏覽器裡，不登入也能玩。

想換裝置接著玩，可以用 Google 登入，進度就會存到雲端。如果這台裝置和雲端的進度不一樣，遊戲會讓你選要用哪一份，也可以勾選「保留另一邊的成就」，成就就不會不見。

## 聊天室

要先用 Google 登入，再取一個暱稱，才能說話。

- 暱稱不能跟別人重複，取了就不能改，所以想清楚再取。
- 登入的玩家都看得到你說的話，請不要留真實姓名、電話或住址。
- 不能貼網址，兩次說話要隔 2 秒。
- 看到不適合的內容，可以到遊戲設定裡的「回報問題或提供建議」告訴我，我會處理。

## 隱私

- 不登入：進度只留在你自己的瀏覽器，不會傳給我。
- 登入 Google：進度會存到雲端，才能換裝置接著玩，也才能用聊天室。
- 聊天室的暱稱和內容，登入的玩家都看得到。

遊戲設定裡也有「隱私與授權」可以看。
