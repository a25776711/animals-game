# wū guī 對對碰

3×3 九宮格烏龜配對小遊戲，純 HTML / CSS / JavaScript，無需建置，手機與電腦瀏覽器都能玩。

## 規則

1. 開局選**幸運色**與**起始包數**（10 / 20 / 50）
2. 按「開包」：每個空格開一包（花 1 包），依**左→右、上→下**一格一格開
3. 開滿後依**左→右、上→下**把所有組合對完，每組各自播報：

| 組合 | 條件 | 獎勵 |
|---|---|---|
| 碰 | 任意 2 隻同色 | +1 包 |
| 連線 | 橫 / 直 / 斜 3 隻同色 | +3 包 |
| 全家福 | 9 隻顏色全部不同 | +5 包 |

   連線優先於碰；同一隻只會算進一組；成立的組合會被清空。
4. 開出幸運色的烏龜時暫停播報，+1 包
5. 包數用完（還有空格要開）或按「結算」，遊戲結束

平均每開一包只回收約 0.6 包，所以目標是「單局獲得多少包」與「撐幾個回合」。

## 成就與存檔

進度（開包數、碰 / 連線 / 全家福 / 幸運色次數、最佳紀錄、成就）一律存在瀏覽器 `localStorage`，沒登入也會保留。
可用 Google 登入把進度存到雲端，換裝置也能延續。

登入時比對這台裝置與雲端的進度：

- 一邊完全包含另一邊（或雲端還沒有資料）：直接用較完整的那份，不打擾
- 兩邊各有對方沒有的進度：跳出視窗讓你選
  - **合併兩邊**：數值取較大者，成就與幸運色取聯集
  - **只用這台裝置的**：雲端被覆蓋
  - **只用雲端的**：這台多出的進度消失
  - **取消登入**：兩邊都不動

## 語音

碰、連線、全家福、幸運色成立時會念「碰，加一包」「連線，加三包」「全家福，加五包」「幸運色，加一包」，語音念完才進下一組。右上角 🔊 / 🔇 可靜音，會記住設定。

## 黑白模式

右上角 🌙 / ☀️ 切換深色與淺色。第一次進來跟著系統設定，之後記住你的選擇。
