# wū guī 對對碰

3×3 九宮格烏龜配對小遊戲，純 HTML / CSS / JavaScript，無需建置，手機與電腦瀏覽器都能玩。

## 規則

1. 開局選**幸運色**與**起始包數**（10 / 20 / 50）
2. 按「開包」：每個空格開一包（花 1 包），依**左→右、上→下**一格一格開
3. 開滿後依**左→右、上→下**把所有組合對完，每組各自播報：

| 組合 | 條件 | 獎勵 |
|---|---|---|
| 碰 | 任意 2 隻同色 | +1 包 |
| 連線 | 橫 / 直 / 斜 3 隻同色 | +3 包 |
| 全家福 | 9 隻顏色全部不同 | +5 包 |

   連線優先於碰；同一隻只會算進一組；成立的組合會被清空。
4. 開出幸運色的烏龜時暫停播報，+1 包
5. 包數用完（還有空格要開）或按「結算」，遊戲結束

平均每開一包只回收約 0.6 包，所以目標是「單局獲得多少包」與「撐幾個回合」。

## 成就與存檔

進度（錢、烏龜、卡片、成就、各項紀錄）一律存在瀏覽器 `localStorage`，沒登入也會保留。
可用 Google 登入把進度存到雲端，換裝置也能延續。

登入時比對這台裝置與雲端的進度：

- 只有一邊在上次同步後有新進度（或雲端還沒有資料）：直接用比較新的那份，不打擾
- 兩邊都有新進度：跳出視窗讓你選
  - **用這台裝置的**：雲端被覆蓋
  - **用雲端的**：這台的錢、烏龜、卡片會被換掉
  - **也保留另一邊的成就**：勾選後兩邊的成就合併，不會因為選了其中一邊就失去成就
  - **取消登入**：兩邊都不動

## 錢與烏龜

- 玩「烏龜對對碰」要用**錢**買包，一包一錢。每開出一隻**烏龜**就會存進錢包，離開時剩下的包數會退還成錢
- 錢只能拿來玩「烏龜對對碰」，烏龜只能拿來玩小遊戲
- 新玩家送 50 錢；第一次用 Google 登入再送 250 錢（可以玩 5 次 50 包）

## 補給站

每天 06:00、12:00、18:00（台灣時間）各開放一份，當天內都能領，跨日就過期。每份可以直接領 200 錢（可以玩 4 次 50 包），或賭一把轉盤：最少 30 錢，最多 350 錢。

## 小遊戲

用烏龜當籌碼，每一種都會扣烏龜，沒有穩賺的玩法：

- **烏龜賽跑**：押一隻烏龜，賠率最高 16 倍
- **21 點**：跟莊家比點數，Blackjack 賠 6:5，可雙倍
- **翻牌記憶**：報名 50 隻烏龜，步數越少獎勵越多，超過 22 步沒有獎勵
- **抽卡圖鑑**：單抽 100、十連 900，抽 4 種稀有度的烏龜卡，集滿 36 種。連續 50 抽沒出傳說，第 50 抽必出

## 語音與設定

碰、連線、全家福、幸運色成立時會念「碰，加一包」「連線，加三包」「全家福，加五包」「幸運色，加一包」，語音念完才進下一組。

右上角 ⚙️ 打開設定視窗，可以調整：

- **音量**：拉到 0 就是靜音
- **語音語種**：普通話或台灣腔
- **明暗**：淺色或深色（第一次進來跟著系統設定）

設定會記在瀏覽器裡，下次進來還在。
